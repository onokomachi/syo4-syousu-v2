## 筆算の画面（2けたの乗数・除数）
- かけ算: かける数が2けた（一の位が0でない）なら 部分積2行→和 の3行を一の位から書く。× 何十 は1行で書く（0を先に書く）。
  小数点をうったあと「終わりの0を消す」段（0をタップ→できあがり）がいつも出る（消すものが無ければ できあがり だけ）。
- わり算: わる数が2けたでも たてる→かける→ひく→おろす。ひいた答えは2けたでもよい。商が0の段も かける・ひくを書く（紙では省く）。
  あまり → 小数部をおろして あまりを答える。検算 → 「わる数×□＋□＝□」を順にうめる。がい数 → 上から3けたまで求めてから四捨五入した答えを入れる。
- 数はすべて整数スケール（`decimalMulDiv.ts`）。`npm run verify` が紙の問題と各レベル400問を整数だけで確かめる。

## 紙との差
- 5（計算のしかた）は、紙は□2つを同時にうめるが、画面では 5①（積）・5②（1/□）を別の問題にしている（数も別）。
- 8〜11 の「式・答え 各5点」は、式をえらぶ→答えを入れる で、一発正解のとき10点（部分点なし）。
- 11①②は同じテープの表を使う（テストの中では同じ表）。
- 実力の階段は app_id ごとに1本なので、下の段＝小数のしくみ（前と同じ8段）・上の段＝かけ算とわり算（6段）の14段。テスト予想は2つの合計 /300。
